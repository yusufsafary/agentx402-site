02

支付：x402

~/pay · minting via x402

每一次购买都是一次 x402 支付。服务器先回 402 Payment Required，代理按份额付清 0.0055 BNB，合约记下份额，收据就是链上记录。没有网页下单，没有连接钱包按钮，你的代理就是收银台。

把下面指令发给你的代理，或让代理直接读 llms.txt 与收购手册。

代理检查你的 Agent ID 与剩余额度，用 quote 核对金额，每笔交易先预览。

你确认后代理执行 buyWithBnb 或 buyWithUsdt，份额记入你的钱包。

点火后用 collectShares 一次取回全部 AX402（每钱包收 0.00024 BNB 取回费）。

      08
      
问答

      ~/faq
    

    

      

        谁可以买？
        
持有 .ai Agent ID 的钱包（SPACE ID 注册表）。没有 Agent ID，合约会直接拒绝购买与免费领取。

      

      

        一份到底多少钱？
        
0.005 BNB 价格 + 0.0005 BNB 服务费 = 0.0055 BNB。可以用 BNB 付，也可以用 USDT 付（按 Chainlink BNB/USD 汇率换算）。

      

      

        点火是什么？
        
第 10,000 份售出的那笔交易就是点火：42.5 BNB 与 850,000,000 AX402 自动组成 PancakeSwap V2 池，LP 发送到销毁地址，佣金篮 5 BNB 自动进入项目钱包，邀请篮 2.5 BNB 分给前 100 名邀请人。不需要任何人手动开池。

      

      

        买完何时能拿到币？
        
份额先记账，点火后调用 collectShares() 一次取回：付费份额每份 100,000 AX402，免费份额每份 10,000 AX402。取回收每钱包 0.00024 BNB。

      

      

        合约有管理员吗？
        
没有所有者，没有暂停开关，没有黑名单，没有代理升级。规则写进代码后按块高执行。合约未经第三方审计，参与前请自己评估风险。

      

      

        为什么叫 402？
        
402 是 HTTP 状态码 Payment Required，为机器间付费预留了三十年。x402 把它变成代理之间的支付语言：先付费，后服务。AGENTX402 把整场出售写成这种语言。
